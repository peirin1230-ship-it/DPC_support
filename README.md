## 概要

DPC（診断群分類）は、入院患者の診断・手術・処置等の組み合わせによって決まる包括評価の分類です。本ツールは、疾患名・手術・処置・薬剤などの条件からDPCコードを素早く検索し、正しいコーディングを支援します。

### 主な特徴

- 疾患名、ICD-10コード、Kコード（手術）、処置コード、薬剤名（一般名・商品名）による横断検索
- **2つの検索モード**: 一覧検索と最適DPCサジェスト
- 全ての分岐パターンのDPCを一覧表示（「下から優先」ルールに沿った優先度フィルタ）
- 定義テーブルにないKコードは「その他の手術あり（97）」として自動的に扱い、その旨を表示
- 定義副傷病の対象ICDを手術あり・なしのフラグに応じて表示
- 年齢・JCS・出生時体重・A-DROPスコア等の条件・重症度ラベルを表示
- 複数DPCの点数比較（比較チャート付き）、入院日数に応じた総点数の自動計算
- 出来高算定手術の自動判定と、包括対象外となる手術・検査・薬剤・対象患者の一覧
- 点数推移グラフ、お気に入り・検索履歴、同一MDC内の類似分類比較
- WCAG準拠のアクセシビリティ対応

## 2つのモード

画面上部のタブで切り替えます。

| モード | 用途 | 特徴 |
|--------|------|------|
| **一覧検索** | 条件に合致するDPCを網羅的に一覧表示 | 全分岐パターンを確認し、ドリルダウンで絞り込み |
| **最適DPCサジェスト** | 段階的な選択で最適なDPCを特定 | 手術→処置1→処置2→副傷病→重症度の順にステップ選択 |

## 一覧検索モード

画面左の4つの検索欄から、いずれか1つ以上の条件を入力して検索します。

### 検索欄一覧

| 検索欄 | 入力内容 | 入力例 |
|--------|----------|--------|
| **ICD-10（病名）** | 病名の一部、ICD-10コード、または分類名（候補に「分類」タグ付きで表示） | `肺炎`、`I510`、`脳腫瘍` |
| **手術（Kコード）** | 手術のKコード、または手術名の一部。定義テーブルにないKコードや出来高算定手術も候補に出ます | `K549`、`腹腔鏡`、`K014` |
| **手術・処置等** | 処置等1・処置等2のコード、または名称 | `SPECT`、`E101`、`DD01` |
| **薬剤検索** | 薬剤の一般名・商品名の一部、または薬剤コード | `リコモジュリン`、`ヘパリン` |

### 検索の仕組み

- 各欄に文字を入力すると、候補がドロップダウンで表示されます（オートコンプリート）
- 候補をクリックして選択し、「検索」ボタンを押します
- 複数の欄を組み合わせて絞り込むことも可能です
  - 例: 「ICD-10: 心不全」+「手術: K552」→ 心不全の分類かつK552の手術区分のDPCのみ表示
- 「クリア」ボタンで全ての検索条件と結果をリセットします
- 検索を実行すると、自動的に検索履歴に保存されます
- 結果が300件を超える場合は「さらに表示」ボタンで追加表示します（検索結果自体は打ち切られません）
- 処置等・薬剤で検索した場合、指定していない側の分岐（処置等1／処置等2）は制約せず全分岐を表示します。実施した処置等は「他に評価される項目」で絞り込みます
- 処置等コードと薬剤を同時に入力し、どちらも処置等2に該当する場合は相関値の大きい方（ツリー図で下＝高優先）を採用します
- 変換テーブルで複数の対応コードが同じDPCに縮約される分類（例: 狭心症 050050 の経皮的冠動脈形成術等における処置等1「なし、１,２あり」）も、変換テーブルの写像に基づいて正しく照合します

### 手術コードの扱い

- **定義テーブルにないKコード**: ICD-10と併せて入力した手術が、その分類の定義テーブルに含まれない場合、DPC制度上は「その他の手術あり（97）」となります。ツールはこの場合 97 の分岐で検索し、黄色のメッセージでその旨を表示します。定義テーブルにないKコードは候補一覧の「97」タグ付き項目（入力したコードそのまま）から選択できます
- **手術による分岐がない分類**: 手術の有無でコードが変わらない分類（例: 一過性脳虚血発作）は、Kコードを入力しても除外されず、「手術による分岐なし」と表示されます
- **組み合わせ手術**: 定義テーブルで「＋（and）」指定されている手術は `K1+K2` の形で候補に表示されます（「組合せ」タグ）。並列された全ての手術を実施した場合のみ該当するため（保医発0321第6号 第2の3(4)）、片方のコードだけを入力しても組み合わせの区分には確定せず、該当する組み合わせがある旨のヒントを表示します
- **手術等管理料・輸血管理料（K914〜K917、K920-2）**: 診断群分類上の「手術」に含まれないため（同 第2の3(8)）、入力しても手術なし（99）として検索し、その旨を表示します
- **選択不可のICD**: C97、T14.0〜T14.9 は診断群分類区分の決定に用いないため警告を表示します（同 第2の1(2)）。T08・T10・T12（部位不明の損傷）は留意コードとして注意を表示します
- **筋骨格系のICD**: ICDテーブルに個別記載のないMコードは、電子点数表の規定どおり `071030` に該当します

### 出来高算定手術の警告

包括評価の対象外となる手術（出来高算定手術）を選択した場合、赤い警告メッセージが表示されます。該当するDPCは出来高で算定されるため、包括点数は適用されません。オートコンプリートのドロップダウンでも「包括対象外」バッジが赤字で表示されます。

## 最適DPCサジェストモード

入力条件から候補DPCを段階的に絞り込み、最適なDPCコードを特定する対話型の検索モードです。「検索1」「検索2」のタブで2つの条件を並行して扱えます。

### 左パネル: 入力フォーム

| 入力欄 | 必須 | 説明 |
|--------|------|------|
| **ICD-10** | 任意 | 疾患のICD-10コード |
| **手術（Kコード）** | 任意 | 実施した手術のKコード |
| **手術・処置等** | 任意 | 処置等1・処置等2のコード |
| **薬剤** | 任意 | 使用した薬剤 |
| **入院日数** | **必須** | 入院日数（総点数の計算に使用） |

- ICD-10・手術・処置・薬剤のいずれか1つ以上の入力が必要です
- DPC対象外のICD-10を入力した場合、エラーメッセージが表示されます
- 出来高算定手術を選択した場合、赤い警告が表示されます
- 定義テーブルにない手術を入力した場合、「その他の手術あり（97）」として候補を絞り込む旨が表示されます

### 右パネル: ステップ選択

```
条件（病態等分類・年齢・JCS等）→ 手術区分 → 処置等1 → 処置等2 → 副傷病 → 重症度
```

- **条件ステップ**: DPCコード7-8桁目で分岐する分類（肺炎の年齢・市中肺炎区分、くも膜下出血のJCS など）では最初に条件を選びます
- **選択肢が1件のみ**: 自動的に選択され、次のステップに進みます
- **選択肢が複数**: ボタン形式で表示され、1つを選択します。出来高算定となる分岐も「（出来高算定）」付きで選択肢に含まれます
- **「← 戻る」ボタン**: 直前の選択を解除して前のステップに戻れます
- **検索フィルタ**: 各ステップ内でコード・名称による絞り込みが可能です
- **入力手術コードの自動フィルタ**: Kコードを入力した場合、該当する手術区分に自動で絞り込まれます

### 結果表示

全ステップの選択が完了すると、絞り込まれた候補DPCが入院日数に基づく総点数順に一覧表示されます。DPCコードをクリックすると詳細モーダルが開きます。

## 検索結果の見方

検索を実行すると、条件に合致する分類（診断群分類番号とその手術区分）に属する**全ての分岐パターンのDPC**が一覧表示されます。

```
[★] [チェック] 050050xx9920xx  狭心症、慢性虚血性心疾患   [Ⅰ] [Ⅱ] [Ⅲ]
               処置1: なし  処置2: ２あり  副傷病: なし    3,087 2,310 1,963
                                                            5日   10日   30日
```

| 要素 | 説明 |
|------|------|
| **★（星マーク）** | お気に入りボタン。☆をクリックで★に変わり、ブラウザに保存されます |
| **DPCコード**（青字） | 14桁のDPCコード。クリックすると詳細モーダルが開きます |
| **出来高**（赤ラベル） | 出来高算定対象のDPCに表示されます |
| **分類名** | 診断群分類の名称 |
| **条件** | 病態等分類・年齢・JCS等の条件がある場合に黄色で表示（例: 「市中肺炎かつ75歳以上」） |
| **手術 / 処置1 / 処置2 / 副傷病** | 各分岐の状態。「あり」の場合は緑色で強調。その分岐が無いDPCでは表示されません |
| **重症度** | 重症度分岐がある場合に黄色で表示 |
| **期間Ⅰ/Ⅱ/Ⅲ** | 各期間の1日あたりの点数と日数。期間Ⅱが存在しないDPCでは「-」 |
| **総点数** | 入院日数を入力している場合に表示。該当日数での包括点数合計 |

### 入院日数の入力

「入院日数」欄に日数を入力すると：
- 各DPCカードに総点数が表示されます
- 期間Ⅲを超える日数がある場合は「出来高○日」と赤字で表示されます（総点数はDPC包括分のみ）
- 総点数順でのソートが有効になります

## 他に評価される項目（ドリルダウン）

検索結果の上部に表示される折りたたみパネルです。検索で見つかったDPCに対して、**コーディングに影響する処置等の項目**を一覧表示します。

1. **初期状態**: 全ての処置等1・処置等2の項目が表示されます
2. **項目を選択**: クリックすると、その項目に対応するDPCに絞り込まれます
3. **優先度フィルタ**: 選択した項目よりも**相関値（優先度）が高い項目のみ**が引き続き表示されます

### 優先度（相関値）の仕組み

DPCの処置等分岐には相関値が設定されています。値が大きいほどツリー図の下＝高優先で、複数の処置等に該当する場合は最も優先度の高いものが適用されます（「下から優先」ルール）。

**例: 050050 の処置等2**

| 相関値 | コード例 | 処置名 |
|--------|----------|--------|
| 1（低） | G005 | 中心静脈注射 |
| 2（中） | J0384 | 人工腎臓 |
| 3（高） | 0022 | tPA |

- G005を選択 → 相関値2以上の項目のみ表示
- 0022を選択 → 「これ以上評価される項目はありません」と表示

「選択をクリア」ボタンで全ての選択を解除し、全DPCの表示に戻ります。

## 詳細モーダル

DPCコード（青字のリンク）をクリックすると、そのDPCの詳細情報がモーダルウィンドウで表示されます。

| セクション | 内容 |
|------------|------|
| **DPCコード** | 14桁のコードと出来高ラベル、条件ラベル |
| **点数情報** | 期間Ⅰ/Ⅱ/Ⅲの点数・日数。入院日数入力時は総点数も表示 |
| **点数推移グラフボタン** | クリックで点数推移グラフを表示（出来高DPCでは非表示） |
| **分岐情報** | 手術（分岐がない分類は「手術による分岐なし」）、処置等1、処置等2、定義副傷病 |
| **副傷病 対象ICD** | 定義副傷病「あり」の場合、対象ICD-10の一覧。副傷病フラグに基づき、手術なしのDPCでは「手術なしの場合」のICD、手術ありのDPCでは「手術ありの場合」のICDを表示。入院時併存症・入院後発症の両方を含み疑い病名は除く旨の注記付き |
| **重症度分岐** | 重症度等の分岐定義。現在のDPCに該当する値が黄色で強調（14桁目で実際に分岐する分類のみ）。判定時点・不明時の扱い（急性膵炎の不明→軽症、Child-Pughの不明項目→1点、妊娠週数不明→34週以上 など）を通知の条項番号付きで注記 |
| **総点数の注記** | 表示点数は診断群分類点数表の点数であり、医療機関別係数・加算・出来高部分を含まない旨を明記 |
| **CCPM対応** | 電子点数表「CCPM対応」シートに支払分類が定義されているDPC（脳梗塞・肺炎）で表示 |

### 折りたたみセクション

- **対象ICD-10**: この分類に含まれるICD-10コードの一覧
- **手術定義**: 手術区分ごとのKコード一覧（実際にDPCが存在する区分のみ）
- **処置等1定義**: 処置等1の区分ごとのコード一覧。特定の手術との組み合わせ時のみ評価されるコードには注記を表示
- **処置等2定義**: 処置等2の区分ごとのコード一覧（薬剤は商品名も表示）
- **同一MDC内の類似分類**

各定義セクションでは、現在のDPCに該当する区分が**黄色**で強調表示されます。

## 点数推移グラフ

詳細モーダル内の「点数推移グラフ」ボタンをクリックすると、入院日数に応じた点数の変化を視覚的に確認できます。

- **ステップチャート**: 期間ごとの1日あたり点数を水平線で表示（期間Ⅱが存在しないDPCでは期間Ⅰの直後に期間Ⅲが続きます）
- **縦の点線**: 期間の境界
- **赤い縦線**: 入院日数のマーカー
- グラフ下部に各期間の点数・小計、入院日数指定時の合計点数と出来高日数を表示

## DPC比較機能

最大4つのDPCを並べて比較できます。

1. 比較したいDPCのチェックボックスにチェックを入れます
2. 画面下部に比較リストバーが表示されます
3. 2つ以上選択した状態で「比較」ボタンをクリック
4. 比較チャートと比較テーブルが表示されます

- 各DPCは総点数の順位に基づいて色分けされます（最高: 赤、最低: 青、中間: グレー）
- 値が異なるセルは**黄色**で強調、数値項目は**最大値が青**、**最小値が赤**
- 入院日数を入力している場合、最下行に**総点数**と出来高日数が表示されます
- お気に入りパネルの「+比較」ボタンからも比較リストに追加できます

## お気に入り・検索履歴

- **お気に入り**: 検索結果の ☆ をクリックして登録（★）。もう一度クリックで解除
- **検索履歴**: 検索を実行するたびに条件を自動保存（最大20件、同一条件は重複せず最新位置へ）
- 「**履歴**」ボタンでパネルを開き、履歴タブ／お気に入りタブを切り替えます
- 履歴・お気に入りは**ブラウザごと**に localStorage へ保存され、キャッシュクリアやシークレットモードでは保持されません

## DPCコーディングの基本的な流れ

1. **傷病名で分類を特定**: 「ICD-10（病名）」欄に主傷病名またはICD-10コードを入力
2. **手術を選択**: 手術がある場合は「手術（Kコード）」欄にKコードを入力。定義テーブルにない手術は自動的に「その他の手術あり（97）」となります
3. **処置等を確認**: 「他に評価される項目」パネルで実施した処置等を選択（優先度の高い方から順に確認）
4. **副傷病・重症度を確認**: 詳細モーダルで副傷病の対象ICD（手術あり・なしで異なる場合があります）や重症度分岐を確認
5. **類似分類の確認**: 「同一MDC内の類似分類」でより適切な分類がないかを検討
6. **点数を確認**: 入院日数を入力して総点数・点数推移グラフ・比較機能で確認。出来高算定手術・薬剤に該当する場合は「出来高算定一覧」も確認
7. **お気に入りに保存**

> **ヒント**: **最適DPCサジェストモード**では、手術→処置→副傷病→重症度のステップを対話的に進められます。

## アクセシビリティ

- **キーボード操作**: 全ての機能がキーボードのみで操作可能
- **スキップリンク**、**フォーカスインジケータ**（`focus-visible`）
- **フォーカストラップ**: モーダル内でフォーカスが閉じ込められ、Escキーで最前面のモーダルだけが閉じます
- **ARIA属性**: オートコンプリート（`role="combobox"`）、タブ（`role="tablist"`）、ダイアログ（`role="dialog"`）
- **モーション配慮**: `prefers-reduced-motion` 設定時にアニメーションを無効化

## 用語集

| 用語 | 説明 |
|------|------|
| **DPC** | 診断群分類（Diagnosis Procedure Combination）。入院医療の包括評価に用いる分類 |
| **DPCコード** | 14桁の分類コード。MDC(2) + 疾患分類(4) + 病態等分類(1) + 年齢等(1) + 手術(2) + 処置等1(1) + 処置等2(1) + 副傷病(1) + 重症度等(1) |
| **x** | DPCコード中で「その分岐が存在しない」ことを表す桁（例: `010061xxxxx0xx` は手術・処置等1・副傷病の分岐なし） |
| **MDC** | 主要診断群（Major Diagnostic Category）。上位2桁で表される大分類（01〜18） |
| **ICD-10** | 国際疾病分類第10版。末尾 `$` のコードは前方一致、`M!!!!` はICDテーブルに個別記載のないMコード（071030） |
| **Kコード** | 診療報酬の手術区分コード。`KKK0`=手術なし、`KKK1`=定義テーブルにない手術（ダミーコード） |
| **手術区分** | 01〜: 定義手術 / 97: その他の手術あり（定義テーブルにない手術） / 99: 手術なし |
| **包括評価** | DPCに基づき1日あたりの定額点数で算定する方式 |
| **出来高算定** | 実施した医療行為ごとに個別に点数を算定する方式 |
| **期間Ⅰ/Ⅱ/Ⅲ** | DPCの入院期間区分。期間Ⅰが最も高い点数、期間Ⅲを超えると出来高算定。期間Ⅱが存在しないDPCもある |
| **処置等1 / 処置等2** | 手術・処置等1（人工呼吸器等）／手術・処置等2（薬剤・検査等）の分岐 |
| **定義副傷病** | DPCの分岐に影響する合併症・併存症。フラグ1=手術あり・なし共通、2=手術なしの場合、3=手術ありの場合 |
| **重症度等** | 一部の分類で設定されている重症度等による分岐（JCS、A-DROPスコア、Child-Pugh分類、脳卒中の発症時期など） |
| **相関値（corrVal）** | 処置等・副傷病の分岐値。base36（1〜9, A, B, …）で大きいほど高優先。「下から優先」ルールの根拠 |
| **出来高算定手術** | 包括評価の対象外となる手術。DPC制度上、出来高方式で算定される |

## 開発者向け情報

### 技術スタック

- **フロントエンド**: React 18 + Vite 5（`vite-plugin-singlefile` で単一HTMLに出力）
- **デプロイ**: GitHub Pages（`master` への push で自動）
- **データ保存**: localStorage（お気に入り・検索履歴・フィードバック）
- **データ**: 令和8年度 DPC電子点数表（`database/001737745.xlsx`、2026-08-13 更新版）をJSONに変換して同梱

### ローカル開発

```bash
npm ci               # 依存パッケージのインストール
npm run dev          # 開発サーバー起動（http://localhost:5173）
npm run build        # 本番ビルド（dist/index.html に出力）
npm test             # データ整合性・検索ロジックのテスト（node:test）
npm run validate:data  # src/data.js が database/ のExcelから再生成した結果と一致するか検証
npm run validate:all   # validate:data + test + build
```

### データ更新

DPC電子点数表の改定・月次更新時は、新しいExcelを `database/` に置いて再生成します。詳細は [docs/update-guide.md](docs/update-guide.md) を参照してください。

```bash
node scripts/generate-data.mjs            # database/ 内の電子点数表を自動検出して src/data.js を生成
node scripts/generate-data.mjs --dry-run  # 件数・整合性チェックのみ
node scripts/generate-data.mjs --file database/新ファイル.xlsx --as-of 20260901
```

- 「変更区分」抹消（1）の行、基準日（既定はExcel内の最新更新日）時点で失効した行、基準日より後に開始する行は除外されます
- 薬剤の商品名別名は `database/drug-aliases.json` で管理します（公式Excelに含まれない運用データ）
- 生成後は `npm run validate:data` と `npm test` が CI（`.github/workflows/validate-dpc.yml`）でも実行されます
